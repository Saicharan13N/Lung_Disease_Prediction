## 🚀 Streamlit Cloud Deployment

[![Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](REPLACE_WITH_LIVE_URL)

### Deploy Instructions:
1. Fork this repo on GitHub
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Click "New app" → Connect to GitHub → Select repo
4. Set main branch and file `lung_disease_streamlit.py`
5. Click "Deploy"

App will be live at `https://your-username-lung-disease-prediction-final.streamlit.app`

## Quick Start (Streamlit Cloud)
```bash
streamlit hello  # Test Streamlit
streamlit run lung_disease_streamlit.py  # Run locally first
```
